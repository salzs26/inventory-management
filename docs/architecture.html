Stack
Technology Choices
Frontend

Vue 3 + Vite

  • Vue 3 Composition API throughout
  • Vite 5 dev server & production build
  • vue-router 4 client-side SPA routing
  • axios HTTP client, centralised in api.js
  • Custom SVG charts no chart library dependency
  • CSS Grid & Flexbox layout system
Backend

Python FastAPI

  • FastAPI modern async web framework
  • Pydantic v2 request & response validation
  • Uvicorn ASGI server
  • uv fast dependency & venv management
  • pytest + TestClient endpoint test suite
  • OpenAPI / Swagger UI at /docs
Data

In-Memory Mock

  • Python list comprehensions for all filtering
  • No database demo-only constraint
  • Resets on restart writes do not persist
  • generate_data.py script to regenerate fixtures

The four global filters — Time Period, Warehouse, Category, and Order Status — are singleton refs in useFilters.js, shared across every view. When any filter changes all views re-fetch independently. Raw API responses are stored in refs; computed properties derive all display values (totals, percentages, chart data) without extra round-trips.

Shared State & Composables
useFilters.js
Module-level singleton refs for the four global filters. Any view calling useFilters() reads and writes the same state.

Lightweight auth state for the demo profile menu. Holds user identity for the UI; no backend authentication is enforced.
